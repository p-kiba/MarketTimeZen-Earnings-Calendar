# マップの探索操作改善

- 企業選択は非モーダルのコンパクトカード。PCは右側、狭い画面は下部。
- カード内の取引一覧は折りたためる。狭い画面では初期状態を閉じ、マップ操作を継続可能にする。
- 一覧には相手先、具体的な関係、金額、公表日を表示。ホバー・キーボードフォーカスで線の説明を表示し、線のホバーも対応する表示中の行に反映。
- 資料・決算の詳細画面は「詳細・決算」から明示的に開く。
- 展開は選択企業一社単位。予告する追加企業・関係数は現在読み込み済みデータとの差分。フィルター・表示上限適用前の件数。
- 「展開を戻す」は展開前の近傍データ、展開済み集合、座標を復元する。ズーム・パンは操作時点のものを維持。新しい中心企業に移ると履歴をクリア。
- 既存企業の座標は固定し、新規企業だけ配置。縮小時は読めないサイズの文字を省略。
- グラフ内に「公表90日以内」「金額あり」「選択企業の供給元／顧客」「提携」「出資・買収」を追加。既存フィルターとAND条件。簡易フィルターはセッション内で保持し、URLには保存しない。
- 線の太さ・非選択企業の濃さは変更なし。線のヒット判定は既存Cytoscapeの許容幅を維持。
