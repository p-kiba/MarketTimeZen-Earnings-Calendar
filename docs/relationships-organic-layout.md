# 企業間マップのつながりに応じた配置

2026-09-26。長方形の外周・格子への整列を、実際の表示対象の取引関係を使う配置へ変更しました。既存のProduct Designで選択されたネットワーク表現と、正方形ロゴ・企業名・契約ラベルの表示を引き継ぐ範囲の変更です。

- 中心企業は配置計算の基準点に置き、企業同士の反発と取引線の引力で位置を調整します。中心企業以外の企業同士の線も計算へ含めます。
- 同じ二社の複数契約は配置上の接続を一つとして扱います。取引の金額、金額の確認状況、お気に入りの有無で引力を増減させません。距離は金額や投資価値を示すものではありません。
- ロゴと下の企業名のため、横132・縦138の領域を確保します。反発計算後にも重なりを解消し、縦横の列へ戻す処理は行いません。これは通常の企業名を想定した領域で、極端に長い名称・多数の契約ラベルの重なりをすべて保証するものではありません。
- 初期配置は企業IDから決まるため、同じ入力と表示領域なら再現できます。表示中は動かし続けず、接続が変わったときだけ回数を制限して再配置します。
- 表示対象と接続が同じ再描画では位置をそのまま使います。展開・絞り込みでは残っている企業の位置を初期値にし、移動を抑えます。位置の保存は現在の画面内のみです。
- 企業をドラッグした後は位置を保存し、線が無関係のロゴ・企業名を通りにくい曲線を再計算します。全線の交差をなくすことを保証するアルゴリズムではありません。
- 配置処理の時間を既存の`renderMs`計測へ含めました。表示上限は既存どおり初期30・展開150社です。

主な変更は`assets/relationships/layout.js`と`map.js`です。キャッシュ識別子を更新して`.site-build`へローカル生成します。金額の判断基準、選択時の線幅と不透明度、既存カレンダー・お気に入り連携は変更していません。

ユーザー指示により、自動テスト・ブラウザーQA・実機テストは実行しません。実表示の見た目と150社時の操作性能は未確認です。再開時は、NVDA・AAPL等の初期表示と周辺展開、表示切替での位置維持、ドラッグ後の線、縦長画面での読みやすさを確認してください。本番へのデプロイは行いません。

前の金額調査で取得した未反映資料は、この配置変更には含めません。停止された資料調査は再開していません。
