# 関係ラベルが線を隠す表示の修正

単一関係の選択・ホバーラベルには位置補正が適用されず、線の真上の白背景が短い線を覆っていた。共通のedgeスタイルへ位置補正を適用し、横方向は線の上、縦方向は線の横へラベルを移動。企業間隔に応じて1行ラベルの幅を制限し、ドラッグ後も再計算する。線幅・透明度・ズーム状態は変更しない。

ローカルサイトを再生成し、Samsungを中心とするCisco–Samsung–Appleの実画面で、選択中のピンクの線と説明文が別々に表示されることを確認。テストスイート・本番デプロイは実施していない。
