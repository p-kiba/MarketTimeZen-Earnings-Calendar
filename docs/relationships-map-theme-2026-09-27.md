# 関係別の色と共通ヘッダー

- 線と取引一覧の色を、供給・サービス=青、提携=緑、出資・買収=紫、グループ=灰、複数種類=茶に変更。同じ種類を束ねた線はその種類の色を維持。
- 選択時のピンク上書きと金額による太線を廃止。ロゴの発光と関係説明で選択を示す。
- 金額ティアの元データは維持。金額の分類・条件は取引詳細で確認できる。
- 「つながりを展開」とその取り消し・再試行の文言を統一。主要ボタンにカレンダーヘッダーの #31343C を採用。
- html_template.py の HEADER_CSS と build_header を共通の出典とする。stage-site.py でマップのヘッダーテンプレートと CSS を生成してからアセットのハッシュを更新する。カレンダーの既存CSS・ヘッダー構成は維持。

確認: ローカルステージング生成、git diff --check、狭幅ブラウザで共通ヘッダー・マップモード・選択カード・選択後の線色を確認。テストスイートはユーザー方針に従い未実行。本番公開なし。
